# Calendar Remix → Studio Regenerate

## Goal
Remix opens Marketing Studio in regenerate mode with the winning post as visual reference and brand kit locked. Distinct from Repost (redistribute same creative).

## Flow
1. User clicks Remix on calendar day/single panel
2. AI remixed caption generated (`grow/ai` mode `remix`)
3. Session stashed: `window.__SE_REMIX_SESSION` (referenceUrl, remixedCaption, brandLocked)
4. Navigate to Studio (`creation-studio`) → apply session to Quick Generate
5. FLF / brand lock forced on; creative direction includes HARD BRAND LOCK
6. User clicks **Generate Remixed Video**

## Non-goals
- Caption-only schedule sidebar handoff
- Attach/reuse original media as the primary path (that is Repost)
