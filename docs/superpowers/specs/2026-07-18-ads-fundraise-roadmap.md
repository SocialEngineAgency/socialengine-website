# Ads + Fundraise Roadmap (MVP + Phase 2+)

Date: 2026-07-18  
Stance: SocialEngine is the **operator layer** between brand brain and money — not Ads Manager, not a caption toy.

## Positioning

- **Ads:** “Learns from organic winners and your inbox, then spends in your brand voice.”
- **Fundraise:** “Fundraising through brand voice, calendar, and donor conversations — not a separate donate-button tool.”

## MVP shipped (this tranche)

### Ads MVP
- Ads command home: local drafts + Meta campaigns, dual KPI shell (shop ROAS/CPA vs charity cost-per-donation / awareness)
- Create flow: objective → creative → budget → **Create Meta Draft (PAUSED)**
- Creative studio: AI copy, optional reel, reviewable variants, ad pack export (not image-only)
- Organic → ad: Calendar **Promote** pre-fills create flow
- Meta Marketing API: draft campaign + paused ad set; ad account select; reconnect CTA when scopes missing

### Fundraise MVP
- Unified JustGiving + Meta fundraisers command center
- Connect states for JG charity ID + Meta Page
- Row actions: open link, Create content, Create ad draft (handoff into Ads)
- Charity-safe copy defaults on ad generation (compassionate, non-clinical)

**Default launch mode:** Meta **Draft / PAUSED** only. Live spend publish is Phase 2.

---

## Ads Phase 2+

- Engage → warm custom audiences (commenters / DM’ers)
- Creative fatigue radar + remix suggestions from brand library
- Angle testing board (fear / hope / proof / urgency) with brand-safe variants
- Inventory-aware catalog ads (OOS suppress, hero / stagnant clearance)
- Live Meta publish + spend caps + approval gates
- Agency command mode (multi-client spend, “needs human today”)
- Rules / alerts (CPA spike, frequency cap, learning limited)

## Fundraise Phase 2+

- Peer-to-peer launch kits (assets, captions, share cadence)
- Campaign narrative engine (awareness → story → urgency → thanks → impact)
- Engage → compassionate ask (context-aware, never salesy)
- Impact proof loop (metrics → thank-you / impact content)
- Compliance-aware asks (no medical advice, region-aware guardrails)
- Deeper Meta fundraiser create/manage UX inside SE (not just list/link)

## Discoverability (later lane — not inside Ads/Fundraise tabs)

- **SEO** — Search Console, content briefs, technical/on-page for product & cause pages
- **GEO** — generative-engine optimization: entity/brand presence in AI answers, FAQ/schema, citation-ready content from brand brain

## Suggested build order

1. Ads MVP + Meta Draft launch (App Review demos for ads permissions) — **done in MVP**
2. Organic → ad handoff — **done in MVP**
3. Fundraise command center + Meta fundraisers list — **done in MVP**
4. Cross-links Fundraise ↔ Ads — **done in MVP**
5. Phase 2 gold ideas (separate specs)
6. Discoverability GEO/SEO lane

## Success criteria (MVP)

- Ecommerce: product → variants → Meta Draft from SE
- Charity: campaign focus or fundraiser → brand-safe creative → Meta Draft; JG + Meta on one Fundraise home
- Screencast-ready for App Review permissions already requested (`ads_*`, `catalog_management`, `manage_fundraisers`, Page/IG publish)
